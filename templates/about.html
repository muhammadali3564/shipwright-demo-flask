About this app

This is a small but real-looking Flask web application built to demonstrate the Shipwright deployment platform.

Tech stack

  • Python 3.11
  • Flask 3.0 web framework
  • Gunicorn WSGI server
  • Bootstrap 5 frontend
  • Docker containerization

How it was deployed

The user pasted this repository URL into the Shipwright dashboard. Shipwright:

  1. Auto-detected the default branch from GitHub
  2. Analyzed the repository structure and identified it as a Python Flask app
  3. Found the existing Dockerfile and used it directly
  4. Created an application in Coolify via API
  5. Triggered the build and assigned a public URL

All without any manual configuration.
